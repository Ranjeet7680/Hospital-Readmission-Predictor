# Contributing Guidelines

Thank you for contributing to the **Hospital Readmission Predictor** project!

---

## 1. Pull Request Workflow

1. Fork the repository and create a feature branch:
   ```bash
   git checkout -b feature/clinical-feature-name
   ```
2. Make your modifications following PEP 8 conventions.
3. Verify that all automated tests pass:
   ```bash
   pytest -v
   ```
4. Commit your changes using conventional commit messages:
   - `feat: add tabular transformer self-attention head`
   - `fix: resolve stroke dashoffset calculation on prediction page`
   - `docs: update system architecture diagram`
5. Push to your branch and open a Pull Request.
